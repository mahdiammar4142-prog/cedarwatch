# CedarWatch — future enhancements

Options that would improve the app. None of these are built yet. Pick from the top of the list first.

## Highest impact

1. **Full Arabic UI** — menus, forms, dashboard, and history, not only map tiles.
2. **My area alerts** — save a neighborhood and get email (then later SMS/WhatsApp) when an outage is reported, confirmed, or restored.
3. **Official area list** — dropdown of Lebanese districts/cadasters instead of free-text “Hamra, Beirut”, so clustering and history stay clean.
4. **PWA / install on phone** — home-screen app, better for reporting from a mobile.

## Trust and data quality

5. **Spam limits** — one report per user per type per area in a time window.
6. **Need more than one “service is back”** — don’t resolve on a single click.
7. **Photos or notes** — optional evidence on a report.
8. **ISP / utility tags** — Ogero vs other ISPs, EDL vs generator, for internet and electricity.

## Deeper product

9. **Richer reliability** — outage hours per week, longest outage, weekday vs night patterns.
10. **Public area pages** — `/areas/hamra` with current status + history, shareable.
11. **Compare areas** — side-by-side Hamra vs Zahle vs Tripoli.
12. **Export** — CSV/JSON of incidents for journalists, NGOs, municipalities.

## Ops and agents

13. **Agent fleet dashboard** — which monitors are online, last check, latency map.
14. **Auto-resolve stale incidents** — if no reports/confirms for N hours, mark likely restored.
15. **Admin tools** — hide junk reports, merge duplicate incidents, pin a nationwide outage.

## Later / only if needed

16. **Grounded Q&A** — answers only from live CedarWatch incidents (“Is there power in Hamra?”), not a generic chatbot.
17. **WhatsApp / Telegram reporting** — useful in Lebanon; more work than the web app.
18. **Offline queue** — save a report when the network is down, send when it returns (especially for electricity/water).

## Suggested next

If you add one more feature after history, choose **full Arabic UI** or **my area alerts**.
